# HTTPS 相机使用说明

## 问题原因

浏览器对访问摄像头等敏感设备有安全限制：
- 只有 `localhost`/`127.0.0.1` 可以在 HTTP 下正常访问
- 局域网地址（如 `192.168.43.6`）必须使用 HTTPS

## 安装和配置

### 1. 安装依赖

在 `frontend` 目录下运行：

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

### 3. 访问应用

现在会显示类似这样的地址：

```
  ➜  Local:   https://localhost:5173/
  ➜  Network: https://192.168.43.6:5173/
```

## 电脑端使用

1. 访问 `https://192.168.43.6:5173/`
2. 浏览器会显示安全警告（"您的连接不是私密连接" 或类似提示）
3. 点击 "高级" → "继续访问" 或 "继续前往"

## 手机端使用

### Android:
1. 在手机浏览器访问 `https://192.168.43.6:5173/`
2. 浏览器会显示警告
3. 点击 "高级" → "继续访问"
4. 授予相机权限

### iOS:
iOS 对自签名证书更严格，需要以下步骤：

1. 在 Safari 访问 `https://192.168.43.6:5173/`
2. 点击"显示详细信息" → "访问此网站"
3. 或者使用以下方案：
   - 使用 ngrok 等内网穿透工具（需要公网域名）
   - 或者暂时在电脑上使用 localhost 测试

## 备选方案

如果手机端还是无法使用，建议：

1. **电脑端测试**：使用 `https://localhost:5173/` 最稳定
2. **使用 ngrok**：
   ```bash
   ngrok http 5173
   ```
   ngrok 会提供 HTTPS 公网地址
3. **部署到正式服务器**：使用真实域名和合法证书

## 注意事项

- 自签名证书仅用于开发测试，生产环境请使用真实证书
- 确保手机和电脑在同一局域网
